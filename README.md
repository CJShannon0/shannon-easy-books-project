# Shannon Easy Books Project

A simple C# project for managing a book-related application in a Unity environment.

## Overview

This repository contains the core Unity project files, scripts, tests, and configuration needed to build and run the project locally. It is structured as a basic starter project and is intended to be expanded as the app grows.

## Features

- Unity-based project setup
- C# scripting support
- Unit test project for validation
- Organized project folders for assets, settings, and scripts

## Getting Started

1. Install Unity Hub and a compatible Unity version (for example, Unity 2022 LTS or later).
2. Clone this repository to your machine.
3. Open the project folder in Unity.
4. Let Unity restore any required packages.
5. Press Play in the Unity editor to run the project.

## Repository Structure

- `Assets/` - Project assets and content
- `Packages/` - Unity package configuration
- `ProjectSettings/` - Unity project settings
- `Scripts.UnitTests/` - Automated tests
- `.github/` - GitHub configuration and workflows
- `.vscode/` - Editor configuration
