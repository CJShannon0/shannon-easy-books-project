# Shannon Easy Books Project

## Overview

This is a bookkeeping software designed for small business owners to keep track of their business transactions, then export a summary of them to give to an accountant.
It is designed to be simple to use, so somebody not familiar with finances should have an easy time using it.

## Features

-Add and view business transactions.
-View and export a yearly summary.
-Supports multiple businesses.
